# GoldEXP — Игровая платформа и форум

**GoldEXP** — это функциональная веб-платформа для геймеров, разработчиков и контент-мейкеров. Проект представляет собой современный форум с системой ролей, личными сообщениями, модерацией и возможностью публикации различного игрового контента.

## 🚀 Основные возможности

### 👤 Управление аккаунтами (`accounts`)
- **Система ролей**: Игрок, Автор контента, Разработчик, Модератор, Администратор.
- **Профили пользователей**: Аватары, биографии, дата рождения и ссылки на социальные сети.
- **Расширенная модель пользователя**: Кастомизированная аутентификация на базе `AbstractUser`.

### 📝 Публикации и контент (`posts`)
- **Категории**: Новости, Гайды, Творчество, Отчёты об ошибках (Bugs) и Идеи.
- **Система тегов**: Классификация контента для удобного поиска.
- **Рейтинги**: Возможность оценки постов пользователями.
- **Медиа**: Поддержка изображений в публикациях.
- **SEO-friendly**: Автоматическая генерация SLUG для URL.

### 💬 Общение (`comments` & `messaging`)
- **Древовидные комментарии**: Возможность отвечать на конкретные комментарии.
- **Личные сообщения**: Система полноценных диалогов (Conversations) между пользователями с темами сообщений и статусом прочтения.

### 🛡️ Модерация (`moderation`)
- **Система жалоб**: Пользователи могут отправлять отчеты о нарушениях (спам, оскорбления, нарушение правил).
- **Панель управления**: Инструменты для разрешения инцидентов модераторами.

## 🛠 Технологический стек

- **Backend**: Python 3.12+, Django 5.2
- **Database**: SQLite (разработка) / PostgreSQL (рекомендуется для production)
- **Images**: Pillow (обработка аватаров и обложек постов)
- **Frontend**: Django Templates, CSS (Vanilla)

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone <url-репозитория>
   cd GoldEXP
   ```

2. **Настройте виртуальное окружение**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   # или
   venv\Scripts\activate  # Для Windows
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```
   *(Если файла requirements.txt еще нет, установите: `pip install django pillow`) *

4. **Примените миграции**:
   ```bash
   python gameforum/manage.py migrate
   ```

5. **Запустите сервер**:
   ```bash
   python gameforum/manage.py runserver
   ```

## 📂 Структура проекта

- `accounts/` — логика пользователей и профилей.
- `posts/` — основная система публикаций.
- `comments/` — система обсуждений.
- `messaging/` — личные сообщения и диалоги.
- `moderation/` — инструменты контроля качества контента.
- `templates/` — HTML-шаблоны оформления.
- `media/` — пользовательские загрузки (аватары, изображения постов).
